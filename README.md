# 📘 Wordie App

**Wordie** is a fun and simple word game app where users can test and grow their vocabulary skills. Built with modern web technologies, Wordie offers an interactive and engaging experience for all ages.

## ✨ Features

- 🧠 Challenging word-guessing gameplay
- 🎨 Sleek, responsive UI
- ⌛ Timer for added difficulty
- 🔄 Randomized word generation
- 📱 Mobile-friendly

## 🛠️ Tech Stack

- **Frontend:** ReactJS
- **Styling:** CSS Modules
- **Deployment:** [Vercel](https://wordie-brown.vercel.app/) 

## 🚀 Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/snowflowerr/wordie.git
   cd wordie-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. Open your browser at `http://localhost:3000`
